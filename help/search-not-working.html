Instant Site Search shows no results or the wrong results

Instant Site Search by operix · Help · Questions: beobjoong@gmail.com

Visitors type into the search box and get nothing, an error line, or results that look wrong. Work through the causes below in order; the first three cover most cases.

1. Wix Site Search app 2. Content types 3. New content 4. Page titles 5. Messages 6. Typo correction 7. Pro features Support

1. The Wix Site Search app is not installed

Instant Site Search does not build its own index. It reads the index that the Wix Site Search app (free, by Wix) keeps for your site. Without that app there is nothing to search.

  1. In your Wix dashboard open Apps → Instant Site Search.
  2. Look at the badge on the Setup card. Connected means the index answered. Search index unavailable means none of the six content types answered.
  3. If it says Search index unavailable, add Wix Site Search from the App Market, then reload the app dashboard.

Connected with an "Unavailable: …" line under it means one or more types did not answer on that check; reload the page to check again. Error means the app itself could not be reached; try again in a minute.

2. The content type is unticked in the widget settings

The widget searches only the content types ticked in its settings panel. If products never show up, Products is probably unticked.

  1. In the editor select the search box and open its settings panel.
  2. Under Search in tick what you want searched: Products, Blog posts, Pages, Events, Services, Forum posts. At least one type always stays selected.
  3. Results per content type (1 to 20) only limits the preview; the rest sit behind each group's Show all link.
  4. Publish the site.

3. The page or post is new

Products appear in results right away. New blog posts and pages usually show up within a minute of publishing. The app also keeps each answer for 60 seconds, so a search run just before publishing can repeat the old answer for up to a minute.

If a post is still missing after a few minutes, open it and check that it is published rather than saved as a draft.

4. Page titles look like "Contact | My Shop Contact us for orders and…"

The Wix index stores each page's title with its SEO description glued on the end. Since version 1.22.0 the app cuts that tail off again: when a title ends with the first 12 or more characters of the description, the overlap is removed and the description shows as the snippet instead. Updates reach your site automatically; nothing to reinstall. If you still see a glued title, send the page address to support.

5. What the messages under the search box mean

"Could not load results. Please try again."

The app answered with an error, the request failed, or every content type timed out (each index call gets 4 seconds). It usually clears on the next try; if it stays, check the Setup badge as in step 1.

"Some results could not be loaded."

Most content types answered but one did not. The results shown are correct; search again in a minute for the rest.

"Too many searches. Please try again in a minute."

The site went over its search budget. Identical searches are served from a 60-second cache and do not count; fresh searches do, up to 600 per site per minute, with a smaller per-caller budget on the public route. Normal visitors do not reach this; a script does.

"Search is not set up for this site yet."

The app has not registered this site. Open Apps → Instant Site Search in the dashboard once, then reload the live page.

"No results for …"

The request worked and nothing matched. Check steps 2 and 3, then try a shorter word.

6. Typo correction works for Korean only

When a Korean query returns nothing, the app looks for the closest term among nearby titles and searches for that instead; the panel then says "Showing results for: …" with the corrected word. This runs only for queries containing Hangul. For other languages the index's own fuzzy matching still catches small misspellings ("abstrat" still returns matches), but no correction hint appears.

7. Synonyms, pinned results or featured suggestions do nothing

These are Pro features. On the Free plan you can still save synonyms and rules in the dashboard, but searches ignore them until the site is on Pro (a running free trial counts as Pro). After an upgrade the change reaches searches within a couple of minutes.

On Pro, if a rule still seems ignored:

  • Synonyms and pins match the whole search term, lower-cased. A synonym for "couch" fires for "couch", not for "blue couch".
  • Pins apply to the first result list only, not to a Show all list, and never to a hidden item.
  • Hidden items are removed from every result list.
  • Edits reach visitors within about a minute of saving.
  • Limits: 200 rules and 20 featured suggestions per site.
